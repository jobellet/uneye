1. OVERVIEW & TASK DESCRIPTION
--------------------------------------------------------------------------------
This experiment tests real-time saccade detection and landing prediction:
  1. Fixation: The participant fixates a central cross (< 1.5 DVA for >= 400 ms).
  2. Stimuli: Three colored targets (Red, Green, Blue) appear equidistant from
     center (eccentricity: 7.0 DVA), in an equilateral triangle layout with
     randomized orientation per trial.
  3. Choice: The participant freely chooses which of the three targets to saccade to.
  4. Real-Time Prediction & Dodge:
     - As soon as the saccade is launched (gaze > 1.8 DVA from center or speed > threshold),
       the algorithm predicts in real-time which target is being targeted:
         * Method A: EyeLive LandingNet deep neural network prediction (pred_x, pred_y, pred_valid)
         * Method B: Kinematic saccadic displacement vector alignment (cosine similarity)
     - The algorithm immediately dodges by shifting the predicted target outward (+5.0 DVA).
  5. Scoring Rule:
     - If the participant's fovea lands within < 2.0 DVA of ANY of the targets
       (by anticipating the dodge or making a rapid corrective saccade),
       the participant scores +10 points!
     - Sound feedback and visual feedback are displayed after each trial.

  ptb_three_targets_game('Source', 'mouse')

  # 1. Launch EyeLive acquisition in the background:
  #    ./eyelive --source dummy --stream stream.eyelive

  # Python:
  python experiments/psychopy_three_targets_game.py --test-mode --num-trials 2

5. CORE ALGORITHM & EQUIVALENT PSYCHOPY IMPLEMENTATION
--------------------------------------------------------------------------------

A. Visual Geometry & PPD (Pixels Per Degree of Visual Angle):
------------------------------------------------------------
Python:
  def compute_ppd(screen_width_px, screen_width_cm, screen_dist_cm):
      px_per_cm = screen_width_px / screen_width_cm
      deg_per_cm = math.degrees(math.atan2(1.0, screen_dist_cm))
      return px_per_cm / deg_per_cm

  ppd = compute_ppd(1024, 53.0, 60.0)
  fovea_radius_px = 2.0 * ppd       # 2.0 DVA threshold
  target_ecc_px   = 7.0 * ppd       # 7.0 DVA eccentricity
  shift_dist_px   = 5.0 * ppd       # 5.0 DVA dodge distance

C. Real-Time Saccade Prediction & Dodge:
---------------------------------------
Python:
  # 1. LandingNet model prediction (if available):
  if state['pred_valid']:
      dists = [math.hypot(target[0] - pred_x, target[1] - pred_y) for target in targets_curr]
      predicted_idx = dists.index(min(dists))
  else:
      # 2. Kinematic trajectory vector cosine alignment:
      gaze_len = math.hypot(gx, gy)
      if gaze_len > 1.0:
          alignments = []
          for tx, ty in targets_orig:
              t_len = math.hypot(tx, ty)
              cos_sim = (gx * tx + gy * ty) / (gaze_len * t_len)
              alignments.append(cos_sim)
          if max(alignments) > 0.50:
              predicted_idx = alignments.index(max(alignments))

  # 3. Apply outward shift:
  orig_x, orig_y = targets_orig[predicted_idx]
  orig_len = math.hypot(orig_x, orig_y)
  out_x = (orig_x / orig_len) * shift_dist_px
  out_y = (orig_y / orig_len) * shift_dist_px
  targets_curr[predicted_idx] = (orig_x + out_x, orig_y + out_y)

D. Landing Scoring Condition (< 2.0 DVA):
----------------------------------------
Python:
  dists_to_targets_dva = [
      math.hypot(target[0] - final_gaze_x, target[1] - final_gaze_y) / ppd

  ]
