1. OVERVIEW & TASK DESCRIPTION
--------------------------------------------------------------------------------
This experiment tests real-time saccade detection and landing prediction:
  1. Fixation: The participant fixates a central cross (< 1.5 DVA for >= 400 ms).
  2. Stimuli: Three colored targets (Red, Green, Blue) appear equidistant from
     center (eccentricity: 7.0 DVA), in an equilateral triangle layout with
     randomized orientation per trial.
  3. Choice: The participant freely chooses which of the three targets to saccade to.
  4. Real-Time Prediction & Dodge:
     - As soon as the saccade is launched (gaze > 1.8 DVA from center or speed > threshold),
       the algorithm predicts in real-time which target is being targeted:
         * Method A: EyeLive LandingNet deep neural network prediction (pred_x, pred_y, pred_valid)
         * Method B: Kinematic saccadic displacement vector alignment (cosine similarity)
     - The algorithm immediately dodges by shifting the predicted target outward (+5.0 DVA).
  5. Scoring Rule:
     - If the participant's fovea lands within < 2.0 DVA of ANY of the targets
       (by anticipating the dodge or making a rapid corrective saccade),
       the participant scores +10 points!
     - Sound feedback and visual feedback are displayed after each trial.

5. CORE ALGORITHM & EQUIVALENT PSYCHOPY IMPLEMENTATION
--------------------------------------------------------------------------------

A. Visual Geometry & PPD (Pixels Per Degree of Visual Angle):
------------------------------------------------------------
Python:
  def compute_ppd(screen_width_px, screen_width_cm, screen_dist_cm):
      px_per_cm = screen_width_px / screen_width_cm
      deg_per_cm = math.degrees(math.atan2(1.0, screen_dist_cm))
      return px_per_cm / deg_per_cm

  ppd = compute_ppd(1024, 53.0, 60.0)
  fovea_radius_px = 2.0 * ppd       # 2.0 DVA threshold
  target_ecc_px   = 7.0 * ppd       # 7.0 DVA eccentricity
  shift_dist_px   = 5.0 * ppd       # 5.0 DVA dodge distance

B. Real-Time EyeLive Memory-Mapped Reader:
-----------------------------------------
Python (from cpp/app/readers/python/eyelive_reader.py):
  from eyelive_reader import StateReader
  reader = StateReader("stream.eyelive")
  state = reader.latest()
  if state is not None:
      gaze_x_px = state['x'] * ppd
      gaze_y_px = state['y'] * ppd
      is_in_saccade = bool(state['in_event'])
      if state['pred_valid']:
          predicted_x_px = state['pred_x'] * ppd
          predicted_y_px = state['pred_y'] * ppd

C. Real-Time Saccade Prediction & Dodge:
---------------------------------------
Python:
  # 1. LandingNet model prediction (if available):
  if state['pred_valid']:
      dists = [math.hypot(target[0] - pred_x, target[1] - pred_y) for target in targets_curr]
      predicted_idx = dists.index(min(dists))
  else:
      # 2. Kinematic trajectory vector cosine alignment:
      gaze_len = math.hypot(gx, gy)
      if gaze_len > 1.0:
          alignments = []
          for tx, ty in targets_orig:
              t_len = math.hypot(tx, ty)
              cos_sim = (gx * tx + gy * ty) / (gaze_len * t_len)
              alignments.append(cos_sim)
          if max(alignments) > 0.50:
              predicted_idx = alignments.index(max(alignments))

  # 3. Apply outward shift:
  orig_x, orig_y = targets_orig[predicted_idx]
  orig_len = math.hypot(orig_x, orig_y)
  out_x = (orig_x / orig_len) * shift_dist_px
  out_y = (orig_y / orig_len) * shift_dist_px
  targets_curr[predicted_idx] = (orig_x + out_x, orig_y + out_y)

D. Landing Scoring Condition (< 2.0 DVA):
----------------------------------------
Python:
  dists_to_targets_dva = [
      math.hypot(target[0] - final_gaze_x, target[1] - final_gaze_y) / ppd
      for target in targets_curr
  ]
  min_dist_dva = min(dists_to_targets_dva)
  is_hit = min_dist_dva < 2.0  # Fovea entered within 2 DVA of any target!
  if is_hit:
      score += 10
      verdict = "TOUCHÉ (+10 pts)"
  else:
      verdict = "ESQUIVÉ (0 pt)"


6. SIMULATION SUR SACCADES RÉELLES (DATASET BENCHMARK)
--------------------------------------------------------------------------------
Pour valider l'algorithme sur des données réelles de poursuite oculaire,
le script `simulate_three_targets_dataset.py` extrait les grandes saccades
du benchmark U'n'Eye (dataset1 et dataset2, comprenant des saccades jusqu'à 12.55°).

Protocole de simulation:
  1. Pour chaque essai, les coordonnées sont centrées sur la fixation pré-saccadique.
  2. "Une des 3 cibles est placée à la position finale réelle d'atterrissage" :
     Target_k = P_end = (x_end, y_end).
     Les deux autres cibles sont disposées à la même excentricité à +/- 120°.
  3. La trajectoire oculaire continue est rejouée à 1000 Hz.
  4. Dès que le regard quitte la fixation (> 1.5 DVA), l'algorithme prédit la cible visée
     et décale la cible prédite de +5.0 DVA vers l'extérieur.
  5. Évaluation à l'atterrissage : distance finale fovéale < 2.0 DVA.

Résultats mesurés sur les 181 saccades larges (dataset1 + dataset2) :
  - Saccades testées (amp >= 3.0°)       : 181
  - Détection déclenchée                 : 181 / 181 (100.0%)
  - Précision de prédiction de la cible  : 181 / 181 (100.0%)
  - Latence moyenne de prédiction        : 18.4 ms après onset (médiane: 18.0 ms)
  - Progression au moment du trigger     : 35.7% de l'amplitude totale
  - Distance moyenne d'atterrissage      : 4.99 DVA (seuil de score: < 2.0 DVA)
  - Taux d'esquive réussie (Dodge Rate)  : 100.0%
  - Hits du sujet (< 2.0 DVA)            : 0 / 181 (0.0% de points marqués)

Résultats selon la distance d'esquive (Shift Distance) sur saccades >= 4.0° :
  - Shift = 1.0 DVA -> Hits: 100.0% (le décalage reste dans le rayon fovéal de 2 DVA)
  - Shift = 1.5 DVA -> Hits: 100.0%
  - Shift = 2.0 DVA -> Hits: 50.5%  (frontière fovéale exacte)
  - Shift = 2.5 DVA -> Hits: 0.0%   (esquive 100% réussie)
  - Shift = 5.0 DVA -> Hits: 0.0%   (esquive 100% réussie, marge de sécurité optimale)

Résultats selon l'amplitude minimale des saccades :
  - Amp >= 3.0° (N=181) : Latence 18.4 ms | Trigger à 35.7% du vol | Précision 100%
  - Amp >= 5.0° (N=64)  : Latence 16.1 ms | Trigger à 22.5% du vol | Précision 100%
  - Amp >= 7.0° (N=31)  : Latence 15.4 ms | Trigger à 16.9% du vol | Précision 100%


7. CODE SOURCE PYTHON DE LA SIMULATION (SIMULATE_THREE_TARGETS_DATASET.PY)
--------------------------------------------------------------------------------
Voici l'implémentation complète reproductible en Python :

```python
import os, glob, math, json, numpy as np

def extract_large_saccades(data_dir, datasets=('dataset1', 'dataset2'), min_amp=3.0):
    saccades = []
    for ds in datasets:
        for s in ('setA', 'setB'):
            xf = glob.glob(os.path.join(data_dir, ds, f'*_X_{s}.csv'))
            yf = glob.glob(os.path.join(data_dir, ds, f'*_Y_{s}.csv'))
            lf = glob.glob(os.path.join(data_dir, ds, f'*_Labels_{s}.csv'))
            if not (xf and yf and lf): continue
            X, Y, L = np.loadtxt(xf[0], delimiter=','), np.loadtxt(yf[0], delimiter=','), np.loadtxt(lf[0], delimiter=',')
            for r in range(min(len(X), len(Y), len(L))):
                row_l, row_x, row_y = L[r], X[r], Y[r]
                in_s, s_idx = False, 0
                for i in range(len(row_l)):
                    if row_l[i] == 1 and not in_s:
                        in_s, s_idx = True, i
                    elif row_l[i] == 0 and in_s:
                        in_s = False
                        e_idx = i - 1
                        amp = float(np.hypot(row_x[e_idx] - row_x[s_idx], row_y[e_idx] - row_y[s_idx]))
                        if amp >= min_amp:
                            t_pre = max(0, s_idx - 100)
                            t_post = min(len(row_x), e_idx + 150)
                            saccades.append({
                                'dataset': ds, 'amp': amp, 'duration_ms': e_idx - s_idx + 1,
                                'x': row_x[t_pre:t_post], 'y': row_y[t_pre:t_post],
                                'onset': s_idx - t_pre, 'offset': e_idx - t_pre
                            })
    return saccades

def simulate(saccades, shift_dist=5.0, fovea_radius=2.0, trigger_dist=1.5):
    latencies, fracs, landing_dists = [], [], []
    correct_preds, hits = 0, 0
    for idx, s in enumerate(saccades):
        x, y, onset, offset = s['x'], s['y'], s['onset'], s['offset']
        x0 = np.mean(x[max(0, onset-40):onset]) if onset > 0 else x[0]
        y0 = np.mean(y[max(0, onset-40):onset]) if onset > 0 else y[0]
        x_end = np.mean(x[offset:min(len(x), offset+40)])
        y_end = np.mean(y[offset:min(len(y), offset+40)])
        xc, yc = x - x0, y - y0
        p_final = np.array([x_end - x0, y_end - y0])
        r_final = np.linalg.norm(p_final)
        theta_final = np.arctan2(p_final[1], p_final[0])

        chosen_k = idx % 3
        targets_orig = np.zeros((3, 2))
        for i in range(3):
            ang = theta_final + (i - chosen_k) * (2.0 * math.pi / 3.0)
            targets_orig[i] = [r_final * math.cos(ang), r_final * math.sin(ang)]
        targets_curr = targets_orig.copy()

        predicted_idx = -1
        for t in range(onset, offset + 1):
            gx, gy = xc[t], yc[t]
            dist_c = math.hypot(gx, gy)
            if dist_c >= trigger_dist and predicted_idx == -1:
                vec = np.array([gx, gy])
                cos_sims = [np.dot(vec, targets_orig[i]) / (np.linalg.norm(vec) * np.linalg.norm(targets_orig[i])) for i in range(3)]
                best_i = int(np.argmax(cos_sims))
                if cos_sims[best_i] > 0.50:
                    predicted_idx = best_i
                    latencies.append(t - onset)
                    fracs.append(dist_c / r_final)
                    out_dir = targets_orig[predicted_idx] / np.linalg.norm(targets_orig[predicted_idx])
                    targets_curr[predicted_idx] = targets_orig[predicted_idx] + out_dir * shift_dist
                    break

        if predicted_idx == chosen_k:
            correct_preds += 1
        dists = [np.linalg.norm(p_final - targets_curr[i]) for i in range(3)]
        min_d = min(dists)
        landing_dists.append(min_d)
        if min_d < fovea_radius:
            hits += 1

    return {
        'num_saccades': len(saccades),
        'accuracy_pct': (correct_preds / len(saccades)) * 100.0,
        'mean_latency_ms': np.mean(latencies),
        'mean_progress_pct': np.mean(fracs) * 100.0,
        'dodge_rate_pct': ((len(saccades) - hits) / len(saccades)) * 100.0,
        'subject_hits': hits
    }
```
