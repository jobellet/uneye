# T01 — Recorder: preallocated memory-mapped session file

Phase 1 · size M · depends on: none (only the contract headers) · branch `jules/T01-<short-name>` · pull request title `T01: Recorder: preallocated memory-mapped session file`

## Goal
Implement `Recorder` (`recorder.hpp`): one memory-mapped file that is the recording buffer, preallocated at start so it cannot run out during an experiment, readable by other processes and crash-safe.

## Read first
* `docs/tasks/README.md` (rules for every task: read it first)
* `cpp/app/include/eyelive/recorder.hpp` (the file layout is part of the contract), `trace.hpp`, `types.hpp`, `state_block.hpp` (you only reserve its 256 bytes)
* `docs/EYELIVE_ROADMAP.md` sections 3.1 and 12.4

## You own (and may change ONLY these paths: CI rejects anything else)
* `cpp/app/recorder/**`
* `docs/tasks/status/T01.md`

## What to implement
Implement every function declared in `recorder.hpp` (`recorder_sizing`, `Recorder::create`, `Recorder::open_readonly`, all virtual methods). Platform code (POSIX mmap and `posix_fallocate`; macOS `fcntl(F_PREALLOCATE)`; Windows `CreateFileMapping`) goes behind a small private header in `recorder/src/`; the Windows branch cannot be built in CI yet: write it carefully against the Win32 documentation and say so in the status file.

## Files you create
* `recorder/src/*.cpp`, `recorder/include/eyelive/recorder_*.hpp` (private helpers only)
* `recorder/tests/test_*.cpp`

## Acceptance tests (all must pass; ctest label = module name)
* sizing: 19 bytes per sample + 512 header + 100000 x sizeof(Event) for the events table; `recorder_sizing(1000, 3600).bytes` is within 1 % of 68 MB + table
* 1e6 samples pushed at 1 kHz, then a 'crash' (reopen with `open_readonly` without calling `close`, using a forked child on POSIX): every sample intact, `count` correct
* a writer thread pushes 2e6 samples while a reader thread checks `x(i) == i` for every `i < size()`: no torn read (also run under TSAN in CI)
* `push` returns false exactly when `count == capacity`; `create` returns an error message (no exception) for a missing directory or an impossible size
* `export_csv` round trip; `set_label` / `set_expert` / events table round trip
* throughput of `push` printed by the test; >= 5e6 samples/s single thread in Release (report; fail only below 1e6)

## Do not
* Do not change any header in `cpp/app/include/eyelive/`.
* Do not implement the state block (task T03) nor read it.
* No exceptions across the interface, no global state, no dependency except the standard library.

## How to build and test
```sh
sh cpp/app/ci/jules_setup.sh
cmake -S cpp -B build -G Ninja -DCMAKE_BUILD_TYPE=Release
cmake --build build
ctest --test-dir build -L recorder --output-on-failure
ctest --test-dir build -L eyelive --output-on-failure   # no other module may break
```
Also run it once with `-DUNEYE_SANITIZE=thread` (CI does the same).
