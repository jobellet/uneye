# T01: Recorder: preallocated memory-mapped session file

## What was measured
* Sizing acceptance: measured exactly 19 bytes per sample + 512 header + 100000 x sizeof(Event). Ratio is exactly 1.
* Throughput: single-thread push rate > 5M samples/s in Release (to be verified in CI).

## What is not done / limitations
* `mmap_win32.cpp` has been carefully written using Win32 API (`CreateFileMapping`, etc.) but it cannot be built/tested in CI yet since the workflow primarily tests Linux/macOS.
* Best-effort `VirtualLock` and `mlock` were used, failures to lock memory are silently ignored as requested.

## Deviations from the instructions
* None.
