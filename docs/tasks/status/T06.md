# T06 status — neural detectors (done by the integrator)

## Delivered
`detect_net/include/eyelive/net_detectors.hpp`, `src/net_detectors.cpp`, `tests/test_net.cpp`, `CMakeLists.txt` (links `uneye_rt`, the existing native engines; no change under `cpp/src` or `cpp/include/uneye`).
* Registered ids: `unet_1+2+3` (`combined.bin`, 2 classes), `unet_andersson5` (`andersson.bin`, 5 classes), `tcn_causal` (`tcn_l10.bin`, label delay 10 read from `tcn_l10.json`), `bitcn_v2` (`bitcn_sup_bitcn_v2.bin`). `make_user_model_detector(path, &error)` loads a trainer model (`UNEY` `.bin` + `<name>.json` sidecar: `classes`, `window` in samples, `deg_per_unit`). `make_detector_with_engine(factory, id, &error)` wraps any `uneye::Engine` (tests, other back-ends).
* `needs_degrees = true`: positions are multiplied by `set_scale()` (fallback: the session's `deg_per_unit`) before the velocities are computed.
* Options: `class_map` = `default3` (default; 5-class model: 0 fixation, 1 saccade, 2 PSO -> 1, 3 pursuit -> 0, 4 blink -> 2) | `identity`; `threshold` (2-class, default 0.5); `min_duration_ms` (default 6 for 2-class models, 3 otherwise).
* Models are looked for in `set_models_dir()`, `$EYELIVE_MODELS`, `./models`, `../models`, `cpp/models`, `../cpp/models`, `../../cpp/models`; the factory returns `nullptr` with a message when the file is missing.
* Documented batch procedure (`detect_all`): window models: windows of W samples every W/2, each sample read from the window whose centre is nearest (a trace shorter than W: one zero-padded window), argmax (2 classes: 1 - P(fixation) > threshold), runs of the mapped class > 0, runs separated by <= 3 samples merged, runs shorter than the minimum duration dropped. Causal TCN: one `step()` per sample, output at t = label of sample t - delay. BiTCN: `uneye::detect` (logit > 0) on the whole trace.
* Streaming (`advance`): window models and the causal TCN go through `uneye::StreamingDetector` (hop 10 ms, decisions ~90 ms after the sample so that they are taken near the window centre), events mapped and merged with neighbours of the same mapped class, published a few samples later; the BiTCN re-runs `uneye::detect` on the last 4 s every 50 ms and publishes events that end more than half a receptive field + 5 samples ago.

## Deviations and open points
* The task asks for a decision delay of about half a window; the declared value follows the implementation (see table). A shorter delay (the first version used 25 ms) made the streaming decisions flicker at movement edges and split events.
* The 5-class golden window contains no movement after post-processing, so label parity for that model is weak; the class mapping is checked on a synthetic trace instead. The injected movements are all classed as saccades by the model (no PSO / pursuit observed), so the PSO -> saccade merge path was not exercised by a real model output.
* `set_models_dir` is process-wide state (the registry factories have no other way to know where the models are); the application sets it once at start-up.
* ONNX back-end is not used here (`make_detector_with_engine` accepts one).
* The independent `agy` review was not possible (headless mode could not read files).
