## Goal
Implement the real-time state block of `state_block.hpp` (seqlock) and the readers that let Psychtoolbox (MATLAB) and PsychoPy (Python) follow the eye in real time through the memory-mapped session file, with no driver and no compilation.

## What to implement
Public header `state/include/eyelive/state_io.hpp`: `class StateBlockWriter { explicit StateBlockWriter(void* block); void init(double rate_hz, double deg_per_unit, int n_classes); void publish_sample(const Sample&, float speed_deg_s, uint8_t cls, bool in_event, uint64_t n_samples); void publish_event(const Event&, uint64_t id); void publish_prediction(float x, float y, float sx, float sy, double t_valid); void set_health(uint32_t flags, uint32_t dropped, float lat_p50_ms, float lat_p95_ms); };` and `bool read_state_block(const void* block, StateBlock* out, int max_retries = 100);`, with the seqlock exactly as described in the contract (C++ atomics and fences). Readers: `readers/python/eyelive_reader.py` (standard library only: `mmap`, `struct`; optional numpy accessors for the sample arrays; `StateReader.latest()`, `follow_events()`), `readers/matlab/eyelive_open.m`, `eyelive_state.m` (`memmapfile`, two reads of `seq` around the copy), `eyelive_follow_example.m` (a commented Psychtoolbox loop) and `readers/README.md` with a PsychoPy example.

## Files you create

## Acceptance tests (all must pass; ctest label = module name)
* a writer thread publishes 1e7 consistent states (all float fields a function of the counter) while a reader thread calls `read_state_block`: every returned block is consistent, retries bounded
* `offsets.json` (written by a test from `offsetof(StateBlock, ...)`) matches the offsets hard-coded in the Python reader and in the MATLAB readers (the test parses both) and `sizeof == 256`
* a test run by ctest (label `python`, skipped with a message if `python3` is missing) writes a state block into a temporary file from C++ and reads it back with `eyelive_reader.py`
* the MATLAB files cannot be run in CI: they must follow the same offsets table, use `memmapfile` formats (`'uint32'`, `'double'`, `'single'`) and be reviewed line by line against `state_block.hpp`; say in `docs/tasks/status/T03.md` that they are untested in MATLAB

## Do not

## How to build and test
