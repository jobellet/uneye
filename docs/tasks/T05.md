## Goal
Implement `IDetector` id `fast_threshold`: the lowest-latency detector, which publishes a PROVISIONAL event a few milliseconds after the onset (for gaze-contingent triggers) and a final event later.

## What to implement
`detect_fast/include/eyelive/fast_detector.hpp` + `src/fast_detector.cpp`, registrar id `fast_threshold`: causal, 2 classes, velocity from the 5-point difference (2 samples of look-ahead), detrended by a causal running median, threshold = lambda x robust noise (default lambda 6, option `lambda`), minimum duration 3 samples (option `min_samples`), a PROVISIONAL event when the threshold has been exceeded for `min_samples` consecutive samples, the FINAL event when the speed has been under 0.5 x threshold for 3 samples (onset moved back to the first crossing). Options `lambda`, `min_samples`, `noise_window_s`. Amplitude and peak speed filled when final. A retracted provisional event (no final movement follows) is announced by a final event with `provisional = false` and `confidence = 0`.

## Acceptance tests (all must pass; ctest label = module name)
