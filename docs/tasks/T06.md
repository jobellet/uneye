## Goal
Wrap the existing C++ network engines as `IDetector`s so they can be chosen as pre-labelers and online detectors, with scale handling and multi-class output.

## What to implement
`detect_net/include/eyelive/net_detectors.hpp` + `src/net_detectors.cpp`: detectors registered as `unet_1+2+3` (`combined.bin`, 2 classes), `unet_andersson5` (`andersson.bin`, 5 classes: 0 fixation, 1 saccade, 2 PSO, 3 pursuit, 4 blink), `tcn_causal`, `bitcn_v2`, and a factory `make_user_model_detector(path)` for a model written by the trainer (task T09: same `.bin` layout + a metadata sidecar `<path>.json` with `classes`, `deg_per_unit`). `needs_degrees = true`: positions are multiplied by `set_scale()` before the network. U'n'Eye works on 200-sample windows (hop 10 ms; decision delay about half a window: fill `decision_delay_ms`), the BiTCN has a 257-sample half field. Option `class_map` (`default3` | `identity`) with default `default3`: the owner's default classes are fixation (pursuit included), saccade (post-saccadic oscillations included) and blink. Model paths are resolved relative to the `cpp/` directory given as test argument and, in the application, relative to the executable (`models/`).

## Files you create
* `detect_net/src/**`, `detect_net/include/eyelive/net_detectors.hpp`, `detect_net/tests/test_*.cpp`

## Acceptance tests (all must pass; ctest label = module name)
* label parity: on the existing golden windows (`cpp/tests/golden_combined.txt`, `golden_andersson.txt`, `golden_causal.txt`, `golden_bitcn_2ch.txt`) the per-sample classes produced by `detect_all` equal the argmax / threshold of the engine output with the documented post-processing
* a 5-class model yields events with the right class ids in its own numbering (option `class_map` = `identity`) and, with the DEFAULT map `default3` (PSO -> saccade, pursuit -> fixation, blink -> blink: 0->0, 1->1, 2->1, 3->0, 4->2), only classes 0, 1, 2; the 2-class models yield class 1 only
* `set_scale(0.5)` multiplies the positions seen by the network by 0.5 (test with a double that records its input)
* unknown model path: the factory returns `nullptr` with an error message
