## Goal
Create the Dear ImGui application shell: window and render-on-demand loop, the tab registry of `gui_tab.hpp`, a status bar, settings persistence, and `MockEngine` so that every tab can be developed without the real engine; plus an offscreen mode that renders frames to an image (the development machine has no usable display).

## What to implement
Finish `cpp/app/gui/CMakeLists.txt` (it already builds `imgui` and `eyelive_gui_lib` from `gui/src/*.cpp`): add the executable `eyelive` (links `eyelive_gui_lib` and, once available, `eyelive_engine`; until the real engine exists it links `MockEngine` only, selected by a `--mock` flag and used by default when `make_engine()` is not available). `shell_main.cpp`: GLFW + OpenGL 3.2 core context, an ImGui frame loop that renders only on input events, on `wants_redraw()` of the visible tab (30 Hz) or once per second, a tab bar built from `tab_registry()` sorted by `order()`, a status bar (source, rate, memory, mode, last warning). `shell_registry.cpp` defines `tab_registry()`. `mock_engine.hpp`: `MockEngine : IEngine` with a synthetic gaze (fixations, saccades, a blink), events, an `ExpertLabels`, a fake trainer that advances a progress curve and a fake trigger log. `--shot <file.ppm> [--frames N] [--tab <title>]`: hidden window, render N frames, `glReadPixels`, write a binary PPM, exit.

## Acceptance tests (all must pass; ctest label = module name)
* `cmake -S cpp -B build -DEYELIVE_BUILD_GUI=ON` builds on Linux (CI installs `xorg-dev libgl1-mesa-dev xvfb`) and on macOS
* `xvfb-run -a build/app/gui/eyelive --mock --shot /tmp/a.ppm --frames 5` exits 0 and writes a PPM whose pixels are not all equal
* with no tab registered the window shows 'no tabs' and does not crash; with a dummy tab registered in a test translation unit the tab appears and `draw` is called
* CPU use of the idle window (no live tab) < 2 % of one core over 10 s (measured with `getrusage`, printed)
* executable size reported in the status file (target < 5 MB stripped)

