# T09 — Trainer: U'n'Eye training in C++ without PyTorch

Phase 1 · size XL · depends on: none (only the contract headers) · branch `jules/T09-<short-name>` · pull request title `T09: Trainer: U'n'Eye training in C++ without PyTorch`

## Goal
Implement `ITrainer` (`trainer.hpp`): the original U'n'Eye U-Net trained by hand-written backpropagation on CPU, with rotation augmentation (on by default, can be disabled), early stopping, 2 to 5 classes (default 3: fixation, saccade, blink), transfer from an existing model and a background worker with progress and cancel. Deliver in two pull requests: T09a layers + gradient checks, then T09b training loop + model I/O.

* `docs/EYELIVE_ROADMAP.md` section 12.3, `foundation/workflow_sim.py` (training on 50 s took 5-80 s with PyTorch on CPU)

## What to implement
T09a: layers with forward AND backward (1-D convolution with padding, the (5, 2) first convolution, transposed convolution, max-pooling, batch normalisation in training mode with running statistics, ReLU, concatenation, softmax + cross-entropy over K classes with an ignore label) in `train/src/layers_*.cpp`. T09b: assembly of the U-Net, Adam, learning-rate decay, early stopping on the held-out part, augmentation, data windows, `std::thread` workers, `make_trainer()`, `save_model` writing the `cpp/models/*.bin` layout + the `<path>.json` sidecar (`classes`, `deg_per_unit`, training summary), loading `init_model` for transfer learning.

## Files you create
* `train/src/**`, `train/include/eyelive/**`, `train/tests/test_*.cpp`
* `cpp/scripts/export_unet_golden.py` (uses the repository's PyTorch `UNet` on CPU: `pip install torch --index-url https://download.pytorch.org/whl/cpu`; writes a small input, the weights, the output, the loss and all parameter gradients to `train/tests/golden_unet_grads.txt`) and the small golden files it produces

## Acceptance tests (all must pass; ctest label = module name)
* T09a: for every layer, analytic gradient against finite differences (relative error < 1e-3 in float, < 1e-6 if the test templates on double) and the parameter gradients of the whole network equal the PyTorch golden within 1e-4
* T09b: on a synthetic dataset created in the test (50 s, 2 classes) training reaches validation event F1 >= 0.9 and stops by early stopping; the saved model loaded with the EXISTING `uneye::make_native_engine` gives the same outputs as the trainer's own forward pass within 1e-5; transfer from that model on a rotated copy converges in fewer epochs than random initialisation
* `rotation_aug = false` really disables rotations (a test counts distinct input orientations); `cancel()` returns within 1 s; the progress callback is called once per epoch with a monotonic `elapsed_s`
* report in `docs/tasks/status/T09.md`: seconds per epoch for 50 s of data with 4 rotations, 1 thread and 4 threads (target <= 5 s and <= 1.5 s per epoch; PyTorch needed 1-2 s per epoch), and the number of parameters

## Do not
* Do not change the `.bin` layout read by `cpp/src/native_engine.cpp`; do not modify `cpp/src/` or `cpp/include/uneye/`.
* No BLAS or third-party library: plain C++17 (`-O3`, auto-vectorisation); SIMD may come later.
* Class-balance weights and similar only if the PyTorch reference does the same.
