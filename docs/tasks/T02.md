## Goal
Implement `ISource` for UDP and CSV file replay, a deterministic synthetic gaze generator with known ground truth, and `RateEstimator`; plus the Python sender tools used to test and to connect an EyeLink.

## What to implement
Implement `make_source`, `RateEstimator`, `UdpSource` (POSIX sockets and Winsock behind one private header; non-blocking read with timeout; 1..50 samples per datagram; binary v1 and the text mode), `FileSource` (speed factor, with or without timestamps) and `SimSource` (public header `source/include/eyelive/sim_source.hpp`: after the run `truth()` returns the generated events with onset / offset / amplitude / class; fixations with drift and tremor, saccades following the main sequence, microsaccades < 1 deg, blinks, configurable white noise, optional positions in pixels).

## Files you create
* `source/src/**`, `source/include/eyelive/sim_source.hpp`, `source/tests/test_*.cpp`
* `cpp/app/tools/send_udp.py` (sends a CSV or a simulated trace as UDP packets in protocol v1, at real time or faster) and `cpp/app/tools/pylink_sender_template.py` (template that forwards EyeLink samples through `pylink`, untested, clearly marked)

## Acceptance tests (all must pass; ctest label = module name)
* UDP loopback at 2 kHz for 10 s with 1, 5 and 20 samples per datagram: no sample lost, timestamps preserved, `dropped_packets() == 0`
* a datagram with a wrong magic or a truncated payload is counted in `dropped_packets()` and never crashes the reader
* text and binary modes both parsed; `FileSource` at speed 0 reads a 1e6-line file in < 2 s, at speed 1 it takes the real duration +- 5 %
* `RateEstimator`: 500, 1000 and 2000 Hz traces with 5 % timing jitter and 1 % missing samples are estimated within 0.5 %, `standard_rate_hz()` returns the standard value, gaps are counted
* `SimSource` is deterministic for a seed and its truth events agree with the generated trace (peak speed / amplitude / duration follow the main sequence within 25 %)

## Do not
* Do not change `cpp/include/uneye/simulator.hpp` or any header in `cpp/app/include/eyelive/`.
* The EyeLink adapter is a template, not a supported feature; do not add the EyeLink SDK.
