## What to implement
`detect_hmm/include/eyelive/hmm_detector.hpp` + `src/hmm_detector.cpp` with a static `DetectorRegistrar` for id `hmm_accel` (`DetectorInfo`: 2 classes, causal = false, `decision_delay_ms` filled with the value your test measures, no provisional events). Options through `set_option`: `offset_rule` = `last` (default, post-saccadic oscillation included) | `first` (first inflection) | `none`, `refine_win_ms`, `margin_ms`. Rate-specific HMM parameters from `cpp/models/universal_hmm.txt` (1000 and 500 Hz; for another rate refuse with a clear error, or document a resampling of the score time axis in your status file). Streaming: incremental velocity / detrended velocity (running median maintained in O(window)), robust noise from the last 4 s updated every 250 ms, fixed-lag Viterbi every hop (<= 5 ms), events published when final, blinks / invalid samples handled like `dsp::drop_invalid_zone_and_short`.

## Acceptance tests (all must pass; ctest label = module name)
* `detect_all` equals `dsp::hmm_detect` + `dsp::refine_events` exactly on the 5 golden traces (`cpp/app/dsp/tests/golden_hmm_accel.txt`, read from the repository)
* streaming against batch on the golden traces and on 20 synthetic traces generated in the test: >= 99 % of events matched, onsets and offsets within 2 samples, no duplicated event
* a final event is published <= 70 ms after its offset at 1 kHz (measured and printed); processing time per sample < 20 us (printed; fail above 100 us)
* invalid samples and a 3-sample blink inside an event do not crash and do not create events
* `set_option` rejects unknown keys and values (returns false)
