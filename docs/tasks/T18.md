## What to implement
`engine/src/**`: source thread (read, timestamp the arrival with the monotonic clock, write the recorder), analysis thread (hop 5 ms: run the active detector, publish events to the recorder events table, the state block and the trigger engine with the arrival time of the sample that completed the event), rate measurement and the preallocation at start (RateEstimator then `Recorder::create`, failing loudly), automatic scale selection when `deg_per_unit == 0` (`select_scale`, once >= 20 events exist), `prelabel`, expert bookkeeping (`ExpertLabels` -> `Recorder::set_expert`), training glue (reviewed material -> `TrainTrace`s scaled by the current scale, `make_trainer()`, background thread priority lowered, core cap), `deploy_trained_model` (detector `user:<name>`), hot swap of detectors at a safe moment, stats (CPU via `getrusage`, latency percentiles). No allocation on the sample path after start.

## Files you create
* `engine/src/**`, `engine/include/eyelive/engine_*.hpp`, `engine/tests/test_*.cpp`

## Acceptance tests (all must pass; ctest label = module name)
* end-to-end test: `SimSource` (task T02) -> engine -> events: all truth events with amplitude >= 0.3 deg found (recall >= 95 % with `hmm_accel`), the session file reloadable with `Recorder::open_readonly`, the state block updated (read with `read_state_block`)
* latency test: `fast_threshold` provisional events reach `ITriggerEngine::on_event` within 1 ms of the sample's arrival (p95, measured)
* streams at 500 / 1000 / 2000 Hz: no drop at 2 kHz, CPU < 5 % of one core (printed)
* `start` fails with a clear message when the file cannot be preallocated; `stop` always leaves a cleanly closed file
* detector hot swap during streaming loses no sample and no event; review -> train -> deploy works with a stub trainer (a test double implementing `ITrainer`)
* TSAN and ASAN clean
