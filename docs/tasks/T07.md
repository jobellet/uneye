## What to implement
Implement every method of `ExpertLabels` (pimpl) and `agreement`. Default classes: 0 fixation, 1 saccade, 2 blink (the owner's choice: pursuit stays in fixation, post-saccadic oscillations in the saccade); up to 5 classes remain possible. Edit rule: the edited event wins, the overlapped parts of other events are trimmed (empty ones removed, one cut in the middle is split). Persistence format of your choice, documented in `annot/include/eyelive/annot_format.md`, versioned, exact round trip.

## Files you create

## Acceptance tests (all must pass; ctest label = module name)
* property test: 10000 random edit sequences (add, remove, move, set_class, split, merge, load_prelabels, exclude, undo, redo) compared with a naive per-sample reference written in the test; `render` always equals the reference; invariants: sorted, non-overlapping, classes in range
* undo back to the beginning gives the initial state, redo reproduces; `clear_history` keeps the current state
* save / load is exact (events, prelabels, exclusions, reviewed ranges)
* `agreement` equals the Python golden file (event F1 and kappa) on at least 30 cases including empty sets and long Andersson-like traces
* invalid requests return false and change nothing
