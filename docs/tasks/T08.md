## Goal
Implement `apply_calibration`, `fit_calibration` and `select_scale` of `calib.hpp`: the convention calibrator fitted on a few annotated stretches, and the label-free choice of the scale that makes a degree-trained network agree with the unit-free HMM.

## What to implement
Implement the three functions with the grid of the Python reference; `select_scale` uses an event-agreement score (declared as `agreement()` in `annotation.hpp`; for your tests keep a local copy of the scoring inside `calib/`, do NOT depend on task T07's implementation) and the default grid `0.005 * 1.4^k` up to 4 (about 25 values).

## Files you create
* `calib/src/**`, `calib/tests/test_*.cpp`
* `cpp/scripts/export_calib_golden.py` (numpy only, copies the pure functions of `foundation/conventions.py`) and `calib/tests/golden_calib.txt`

## Acceptance tests (all must pass; ctest label = module name)
* planted conventions: events shifted by known onset / offset offsets, an amplitude floor and merged pairs are recovered by `fit_calibration`
* parity with the Python reference on at least 10 trace / event sets of the golden file (same chosen parameters, same score within 1e-6)
* `select_scale` with a test-double detector that is correct only near scale 0.04 chooses a scale within one grid step; `low_confidence` is set when the curve is flat or the best agreement < 0.4
* `fit_calibration` takes < 1 s for 50 s of data with 30 events
