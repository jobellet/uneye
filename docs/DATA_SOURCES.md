# Data used by the landing-estimate work (nothing below is in git; `data/GazeBase/`, `data/EyeTrackUAV2/`, `data/Andersson/`, `archive/` are ignored)

| Data | Where it comes from | Licence | Used for | Status |
|---|---|---|---|---|
| **GazeBase v2.0** (322 participants, 9 rounds, 1 kHz EyeLink 1000; tasks RAN = random saccades with the target position, TEX = reading a poem) | figshare, DOI [10.6084/m9.figshare.12912257](https://doi.org/10.6084/m9.figshare.12912257); file `GazeBase_v2_0.zip` (6.71 GB), direct link https://ndownloader.figshare.com/files/27039812. Paper: Griffith et al., Scientific Data 2021, https://www.nature.com/articles/s41597-021-00959-y | CC BY 4.0 (figshare API) | landing estimate with / without the known target, candidates, reading, subject history | downloaded 2026-10-15 to `data/GazeBase/`; extractions `ran_saccades.npz` (163 594 saccades), `tex_saccades.npz` (86 945) |
| **Andersson et al. 2017** (500 Hz, SMI Hi-Speed 1250, human coders RA / MN; images, videos, dots) | folder names (`etdata_EyeMovementDetectorEvaluation_annotated_data`) point to the authors' repository https://github.com/richardandersson/EyeMovementDetectorEvaluation (address inferred from the names, not re-checked); also the unlabeled "Lund2013" group of `archive/` | GPL-3.0 (data/AGENT.md) | first analyses and networks (test split = 513 saccades of the article's two-coder trials) | provided by the owner in `data/Andersson/`; the stimuli (images, videos) are NOT included |
| **Bellet et al. 2019, datasets 1-4** (U'n'Eye benchmarks, 1 kHz / 500 Hz) | https://github.com/berenslab/uneye (original repository) and the paper https://www.biorxiv.org/content/early/2018/06/29/359018 | see the original repository | tables of the shipped gaze engine (sets A of datasets 1 and 2), extra training rows | in `data/dataset1..4/` (owner) |
| **EyeTrackUAV2** (1 kHz binocular, 43 UAV videos, 30 participants free viewing + 30 task) | ftp://ftp.ivc.polytech.univ-nantes.fr/EyeTrackUAV2/ (anonymous; passive mode times out, use `curl --disable-epsv`). Paper: Perrin et al., Drones 4(1), 2020, https://www.mdpi.com/2504-446X/4/1/2 | free download per the README | planned: saliency candidates on real videos | only the gaze of 9 DTB70 sequences in free viewing downloaded (245 MB, `data/EyeTrackUAV2/RAW_FV`); the frames come from DTB70 (row below); the display geometry (native size, centred: screen = frame + (320, 180) px) was measured by comparing one file of each coordinate system |
| `archive/` (unlabeled recordings: EMTeC, GazeBase (1 file), Lund2013, GazeCom, 360EM, VEDB, ...) | owner's multi-source set, see `docs/ARCHIVE_DATA.md` | per source | pre-training of the self-supervised models | local; note: its "Lund2013" group contains the Andersson test trials (audit 2026-10-15) |

| **DTB70** (70 drone videos, 15 777 frames, 1280 x 720) | Kaggle copy `galaxythereal/dtb70-sot` (https://www.kaggle.com/datasets/galaxythereal/dtb70-sot, 1.45 GB, licence 'Unknown', third-party mirror of Li & Yeung, AAAI 2017, https://doi.org/10.1609/aaai.v31i1.11205), downloaded by the owner as `data/archive 2.zip` | unknown (research use only, not redistributed) | frames of the 9 sequences used by EyeTrackUAV2 (3 632 frames, same count as the EyeTrackUAV2 README) | extracted to `data/DTB70/` |

Not downloaded: DIEM (public version is 30 Hz, not usable for saccades).
